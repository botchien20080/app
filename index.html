Dữ liệu

Phần mềm được lưu bằng LocalStorage. Bạn có thể xuất toàn bộ dữ liệu thành JSON để sao lưu hoặc chuyển sang máy khác.

Kiến trúc

100% Local: HTML + CSS + JavaScript, không framework bắt buộc. Có thể chạy trực tiếp bằng cách mở index.html.

Sẵn sàng nâng cấp: có thể thay LocalStorage bằng PHP/MySQL, Node.js, API hoặc Google Sheets sau này mà không phải làm lại giao diện.
